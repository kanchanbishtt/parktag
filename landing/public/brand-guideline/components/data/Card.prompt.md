The owner/scanner card. White, generously rounded, lifted with a navy-tinted shadow — never a flat outline.

```jsx
<Card icon={<IconTile name="shield" />} title="Admin access" sub="Sign in to manage tags, issuance batches, owners, and activity.">
  {form}
</Card>
```

Use `soft` for stacked dashboard sections, `premium` only inside the activation flow. Admin console screens use `AdminCard`.
