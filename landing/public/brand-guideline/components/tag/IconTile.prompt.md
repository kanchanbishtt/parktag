Rounded tinted square behind an icon — the only place ParkTag uses a coloured fill decoratively.

```jsx
<IconTile><Icon name="shield" size={22} /></IconTile>
<IconTile size="sm" tone="soft"><Icon name="share" size={16} /></IconTile>
```

Alternate `accent` and `soft` down a list so consecutive rows differ slightly, as the product does.
