API Tokens

A token lets a script or tool call the admin API without signing in. Read tokens can view data; write tokens can also change promo codes and shop settings. A token can never manage admins, issue or delete tags, or create other tokens. You only see your own tokens.

Create a token

Up to 90 days, and at most 10 active tokens at a time. Creating and revoking tokens is recorded in the audit log.
